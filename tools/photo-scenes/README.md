# Фото-сцены из фотобокса

Скрипты, которыми фото из фотобокса превращены в «интерьерные» кадры:
посуда вырезается с фона и ставится на мрамор / льняную скатерть / тёмный стол
с мягким светом из окна и тенями листьев.

Нужен Python 3 и пакеты: `pip install rembg pillow numpy scipy onnxruntime`
(при первом запуске `rembg` скачает модель ~1 ГБ).

1. Положите исходные фото в `src/` как PNG: `src/s1.png`, `src/s2.png`, …
2. Вырежьте фон: `python3 cut.py birefnet-general s1 s2`
3. Опишите сцену в `scenes.py` (словарь `jobs`) и соберите: `python3 scenes.py <имя>`
4. Сохраните WebP для сайта (`export.py`): `python3 export.py`

- `flatlay(...)` — для фото сверху (раскладка на столе),
- `angled(...)` — для фото под углом (стол уходит в перспективу),
- `kind`: `marble`, `linen`, `plaster`, `dark`.
