# Maison Aelyra — сайт шоурума посуды

Одностраничный сайт на чистом HTML/CSS/JS — без сборки и зависимостей.
Instagram: [@showroom_aelyra](https://instagram.com/showroom_aelyra)

## Как посмотреть

Откройте `index.html` в браузере (двойной клик) — сайт работает и без сервера.

## Как редактировать

**Весь контент находится в одном файле — `content.js`.** Тексты, фото, товары,
контакты и порядок блоков меняются там. Вёрстку трогать не нужно.

### Контакты
В блоке `contacts` заполните нужные поля. Пустые поля на сайте не показываются.

```js
contacts: {
  instagram: 'showroom_aelyra',
  whatsapp: '77001234567',        // только цифры с кодом страны
  phone: '+7 700 123 45 67',
  city: 'Алматы',
  address: 'ул. Примерная, 1',
  hours: 'Ежедневно 10:00–20:00',
  mapUrl: 'https://2gis.kz/...',
},
```

Если указан `whatsapp`, кнопки «Заказать» открывают WhatsApp с готовым текстом
(шаблон — `orderMessage`). Если нет — открывается Instagram Direct, а текст
сообщения копируется в буфер обмена.

### Добавить товар
В секции `type: 'catalog'` скопируйте любой объект в `items` и поменяйте поля:

```js
{
  name: 'Название товара',
  collection: 'Nauryz',             // по этому полю работают фильтры
  image: 'assets/img/my-photo.webp',
  text: 'Короткое описание.',
  details: ['Деталь 1', 'Деталь 2'],
  price: '45 000 ₸',                // или 'Цена по запросу'
  badge: 'Новинка',                 // необязательно
},
```

Фото кладите в `assets/img/`. Лучше всего вертикальные 4:5 (например 800×1000), формат WebP или JPG.

### Добавить, убрать или переставить блок
Блоки страницы — это массив `sections`. Они выводятся в том же порядке.

- **Переставить** — перенесите объект выше или ниже.
- **Скрыть** — добавьте `hidden: true`.
- **Добавить** — скопируйте объект нужного типа и измените тексты.

| `type`        | Что это                                            |
|---------------|----------------------------------------------------|
| `hero`        | Главный экран со сменой фото (`slides`)            |
| `intro`       | Текст о бренде + цифры (`stats`)                    |
| `collections` | Коллекции: фото + описание, чередуются             |
| `features`    | Фото + нумерованный список преимуществ             |
| `banner`      | Полноэкранное фото с заголовком и кнопкой          |
| `catalog`     | Каталог товаров с фильтрами и окном «Подробнее»     |
| `gallery`     | Галерея (`size`: `wide`, `tall`, `big`) с просмотром |
| `services`    | Иконки услуг (`icon`: `table`, `gift`, `truck`, `chat`) |
| `instagram`   | Блок Instagram с плиткой фото                      |
| `contact`     | Контакты + фото, `map: true` — карта по адресу     |
| `html`        | Любой собственный HTML                             |

В текстах можно использовать `<br>`, `<em>` (золотой курсив в заголовках) и `<strong>`.

Ссылки в кнопках (`href`): `'#catalog'` — якорь на блок, `'instagram'`, `'whatsapp'`,
`'order:Название товара'` — сообщение о заказе, или обычный адрес `https://…`.

### Новый тип блока
В `assets/js/app.js` добавьте функцию в объект `sections` — она получает объект
секции из `content.js` и возвращает HTML. Стили — в `assets/css/style.css`.

### Цвета и шрифты
В начале `assets/css/style.css` — переменные `--bg`, `--ink`, `--gold` и шрифты.

## Публикация
Сайт опубликован на GitHub Pages: https://adlet-commits.github.io/Maison-Aelyra/
(Settings → Pages → Deploy from a branch → `gh-pages`, папка `/ (root)`).

Чтобы обновить сайт — отправьте изменения в ветку `gh-pages`.
При переходе на свой домен (например, maisonaelyra.kz) укажите его в Settings → Pages → Custom domain
и замените адрес `adlet-commits.github.io/Maison-Aelyra` в `index.html` (canonical, og:url, og:image).

## Структура
```
index.html            каркас страницы и SEO-теги
content.js            ← весь контент сайта
assets/css/style.css  стили
assets/js/app.js      сборка страницы из content.js
assets/img/           фото (WebP)
tools/photo-scenes/   скрипты обработки фото из фотобокса
```
